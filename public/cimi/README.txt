Taruh foto-foto kelinci Cimi (.jpg, .jpeg, .png, .webp, .gif) di dalam folder ini!
Semua file foto di folder `public/cimi/` akan otomatis muncul di galeri "Cimi's Memories".

Tips opsional untuk kategori album otomatis berdasarkan nama subfolder atau nama file:
- `public/cimi/baby-cimi/...`   -> Album "Baby Cimi"
- `public/cimi/tidur-gemoy/...` -> Album "Tidur Gemoy"
- `public/cimi/jam-makan/...`   -> Album "Jam Makan"
- `public/cimi/eksplor/...`     -> Album "Eksplor"

Kamu juga dapat mengatur caption, tanggal, atau urutan foto secara manual di `src/data/cimiPhotos.js`.
